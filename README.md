# TitipAnak

Aplikasi web untuk layanan penitipan anak (daycare). Orang tua dapat menitipkan anak, sementara pengelola mengatur pengasuh dan jadwal shift agar anak selalu terpantau.

## Fitur Singkat

- **Manajemen jadwal shift pengasuh**: buat, lihat, cari, dan filter jadwal.
- **Tampilan kalender**: jadwal shift ditampilkan per minggu dan per bulan.
- **Kelompok usia**: anak dikelompokkan berdasarkan rentang usia.
- **Jadwal kegiatan** per kelompok usia (admin) dan tampilan harian untuk pengasuh.
- **Presensi anak**: check-in, check-out dengan pencocokan Penjemput Terdaftar/izin penjemputan, dan kehadiran hari ini.
- **Rekap kehadiran** untuk admin dengan filter, ringkasan per anak, dan penghapusan beralasan yang tercatat di log.
- **Hak akses per peran** menggunakan Spatie Laravel Permission.

Stack: Laravel 13, Livewire 4, Spatie Laravel Permission. Panduan pemasangan ada di [instalasi.md](instalasi.md), skenario demo di [docs/skenario-demo.md](docs/skenario-demo.md). Jalankan tes dengan `php artisan test`. Zona waktu bawaan `Asia/Jakarta` (ubah lewat `APP_TIMEZONE`).

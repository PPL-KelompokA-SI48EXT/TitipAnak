# TitipAnak

Aplikasi web untuk layanan penitipan anak (daycare). Orang tua dapat menitipkan anak, sementara pengelola mengatur pengasuh dan jadwal shift agar anak selalu terpantau.

## Fitur Singkat

- **Manajemen jadwal shift pengasuh**: buat, lihat, cari, dan filter jadwal.
- **Tampilan kalender**: jadwal shift ditampilkan per minggu dan per bulan.
- **Kelompok usia**: anak dikelompokkan berdasarkan rentang usia.
- **Hak akses per peran** menggunakan Spatie Laravel Permission.

Stack: Laravel 13, Livewire 4, Spatie Laravel Permission. Panduan pemasangan ada di [instalasi.md](instalasi.md).

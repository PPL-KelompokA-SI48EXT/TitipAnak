Design System

Panduan tampilan untuk seluruh halaman aplikasi manajemen daycare TitipAnak, mengikuti gaya presentasi PBI kita: flat, ramah, berwarna pastel, dengan garis tepi hitam tegas. Anggap file ini sebagai template: semua komponen di bawah bisa langsung disalin.

Admin Pengasuh Orang Tua Laravel 13 · Livewire 4 · Spatie Permission

1. Prinsip desain

Orang tua yang cemas harus merasa tenang. Pengasuh yang sibuk harus bisa input cepat. Jadi tampilannya hangat, jelas, dan tidak ramai.

🎨
Flat & tegas
Tanpa shadow, tanpa gradient. Pemisah antar elemen cukup border hitam 1.5px.
🧩
Satu warna, satu makna
Setiap aktor dan modul punya warna pastel sendiri. Konsisten di seluruh halaman.
🫶
Ramah & lega
Sudut membulat 10px, spasi lega, teks besar. Satu halaman satu tujuan.

2. Warna

Latar selalu putih. Pastel dipakai sebagai warna blok (kartu, header tabel, badge). Teks dan border selalu hitam --ta-ink. Klik swatch untuk menyalin hex.

4. Bentuk, border & spasi

Semua elemen interaktif dan kartu memakai bahasa bentuk yang sama.

Border
1.5px solid ink untuk kartu, tombol, input. 1px untuk baris di dalam daftar & sel tabel.
Radius
10px untuk hampir semua elemen. 50% untuk bubble ikon. Pill (999px) hanya untuk badge & tab.
Elevasi
Tidak ada shadow. Efek hover cukup naik 2px (translateY(-2px)).

Di Livewire

{{-- Search + filter: debounce supaya tidak query tiap ketikan --}}
<input class="input" type="search" wire:model.live.debounce.300ms="q" placeholder="Cari nama anak…">
<select class="select" wire:model.live="paket">…</select>

{{-- Modal: state di komponen, tampilkan dengan @if --}}
<button class="btn" wire:click="$set('showForm', true)">Tambah</button>
@if ($showForm)
  <x-modal wire:model="showForm" title="Tambah Kelompok Usia"> … </x-modal>
@endif

// Komponen: reset halaman saat filter berubah
public function updated($name) { if (in_array($name, ['q','paket','status'])) $this->resetPage(); }

Tips: simpan filter di URL dengan #[Url] supaya bisa di-bookmark dan tetap ada setelah refresh. Konfirmasi hapus selalu pakai modal coral, jangan confirm() bawaan browser.

Responsif

Breakpoint: ≤640px mobile (1 kolom, sidebar jadi bar horizontal), ≤960px tablet, di atasnya desktop. Area sentuh minimal 44px. Orang tua dominan memakai HP, jadi desain mobile-first untuk halaman orang tua.

7. Implementasi di Laravel

Pindahkan token ke resources/css/app.css, lalu bungkus komponen jadi Blade component supaya konsisten.

Token (Tailwind v4 @theme)

/* resources/css/app.css */
@import "tailwindcss";

@theme {
  --font-sans: "Poppins", ui-sans-serif, system-ui, sans-serif;

  --color-ink:      #1B1B1B;
  --color-muted:    #6B6B6B;
  --color-cream:    #FFF6D6;
  --color-yellow:   #FFD43B;
  --color-blue:     #A8D4FF;
  --color-mint:     #A8E6CF;
  --color-lavender: #CDBDFF;
  --color-coral:    #FF9E80;

  --radius-ta: 10px;
}

Blade component

{{-- resources/views/components/card.blade.php --}}
@props(['tone' => 'white'])
@php
  $tones = ['white' => 'bg-white', 'yellow' => 'bg-yellow', 'blue' => 'bg-blue',
            'mint' => 'bg-mint', 'lavender' => 'bg-lavender', 'coral' => 'bg-coral', 'cream' => 'bg-cream'];
@endphp
<div {{ $attributes->class(['border-[1.5px] border-ink rounded-ta p-6', $tones[$tone]]) }}>
  {{ $slot }}
</div>

{{-- pemakaian --}}
<x-card tone="mint">Orang Tua</x-card>

Konvensi

Struktur view
Komponen UI di resources/views/components/ (x-button, x-card, x-badge, x-input). Halaman Livewire di app/Livewire/{Admin,Pengasuh,OrangTua}/. Layout dasar di components/layouts/app.blade.php.
Role & tampilan
Pakai Spatie Permission untuk menyembunyikan menu: @role('admin'), @can('verifikasi pendaftaran'). Warna aksen sidebar mengikuti role: kuning, biru, mint.
Livewire
Tampilkan state loading dengan wire:loading (tombol jadi opacity-50). Error validasi memakai gaya .field--error. Notifikasi sukses memakai alert mint.
Ikon
Ikon digambar di dalam bubble putih berborder (lingkaran 56px). Pakai set ikon outline satu gaya (mis. Heroicons outline), stroke 1.75–2px, warna ink.

8. Do & Don't

✓
Lakukan
  • Latar putih, blok warna pastel, border ink 1.5px
  • Satu warna pastel per aktor / modul secara konsisten
  • Poppins bold untuk judul, regular untuk isi
  • Radius 10px di semua kartu, tombol, input
  • Fokus keyboard terlihat jelas pada semua elemen interaktif
  • Bahasa Indonesia yang sederhana, tanpa istilah teknis
✕
Jangan
  • Memakai shadow, gradient, atau glassmorphism
  • Menambah warna di luar palet (mis. biru tua, merah pekat)
  • Teks abu muda di atas warna pastel
  • Border tipis abu-abu; border selalu ink
  • Lebih dari satu tombol kuning utama per area
  • Memakai warna saja sebagai penanda status; tambahkan label teks
